# 单指纹全模块逐步骤导出

样本：hyh_L1 / pair_100，实际normal原始采集，五相位、十张wi/wo CSV。

主链：00原始准备 → 01 V7 → 02去噪 → 03传统分割 → 05 FFQ（使用03的外部Mask）。
04 MobileSeg为同输入参考分支；06一致性为从02输入的独立校准分支；07生长为从02创建固定人工缺口的独立演示，不代表真实采集缺陷、不替换主链。

每个目录按01、02…编号。复数一步有实部、虚部、幅值、相位四张图；网络每个实际叶子层都有全部通道拼图，原始值保存在NPZ。方向、相位、置信度和特征图都不是新的指纹照片。

优先打开“打开查看_全步骤图集.html”。图片目录也可直接使用。每张图显示范围、输入形状、原值键和备注在“步骤与显示范围.json”。一般图独立min-max显示；小图最近邻放大。不能从独立拉伸后的明暗直接比较能量。

没有训练新模型、没有挑选占优样本、没有修改原数据或算法权重。数值与原接口的核验见验证与来源.json。共376张步骤图片，含8个模块/输入目录。
