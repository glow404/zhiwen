湿指纹识别研究周报（2026-09-20）

本周进展。 先在现有湿指纹数据的六折手指互斥交叉验证中，以局部＋整图融合取得总体实际 FAR 0.47%、FRR 9.30%、宏 EER 3.17%；再将六折不同权重合并为一份统一模型，从原始湿图重跑评分。在统一模型的404张查询回测中，验证目标 FAR=0.5% 时实际FAR 0.38%、FRR 10.89%、EER 3.18%。统一模型的FAR合格，FRR仍差0.89个百分点，因此尚未满足单模型的完整目标。六折FAR/FRR是六折错误数合并计算，EER是宏平均；不能把六折0.47%/9.30%写成这份单模型的结果。两种实验均使用参与开发过的现有湿图，不是新手指盲测。

一、输入与数据划分

当前 wet_new 有790张、wet_restore/wet_restore 有292张湿图；合计12根手指、1082张，与实验清单逐文件哈希一致，没有未纳入的湿图。人工先前删除明显失真的图像之后，每指固定20张湿图模板，合计240张；剩余602张湿图查询。六折每折8指训练、2指验证、2指测试，每指测试一次；测试折的每张查询面对包含全部12指的注册库，因而有1次同指和11次异指声明。模板和查询始终都是湿指纹。

二、图像到局部描述子的构建

1. 关键点与方向。 对灰度湿图做 SIFT 检测，按响应保留最多300个关键点，保存每点位置、尺度和 SIFT 主方向。SIFT 在这里负责定位及提供方向线索；最终128维描述子由学习网络生成，不是原生 SIFT 描述子。原图的梯度结构张量还生成脊线切向场，以 cos(2θ)、sin(2θ)、方向一致性 三通道表达180°对称的纹线方向。方向场分支曾作过消融，但当前最优模型使用原始未硬旋转对齐的图块主路；方向信息主要进入候选旋转搜索与几何对应一致性，而没有直接拼入最终128维向量。

2. 自相关辅助特征。 对局部图块去均值、标准化并加窗，用傅里叶变换计算二维自相关，中心峰值归一化。自相关能显露指纹脊线的周期纹理。原始网络包含预测自相关图的辅助头，早期训练利用它约束纹理表征；第45/50版最终验证打分不读取自相关预测图，也不能把它说成最终融合分数的第三路。下图左侧为真实32×32图块，右侧为由它直接计算的自相关目标图。

3. 多尺度骨干、空间注意力与描述子。 灰度图块先映射到[-1,1]，进入高分辨率残差骨干：原分辨率、2倍/4倍/8倍下采样的特征经横向1×1投影后上采样、拼接融合。网络随后为32×32空间位置预测注意力权重，Softmax后对特征图加权池化，再经全连接投影与L2归一化，形成128维局部描述子。这是空间注意力池化，不是Transformer式Q/K/V自注意力；另有可靠性和自相关辅助头，但最终评分主路使用描述子。下图从本次第45版折内权重实际前向生成，热图表示一个图块内部的注意力权重。

此前还对34例误拒、误受和正确接收做过注意力回投、关键点覆盖与遮挡诊断，未见注意力普遍集中在明显错误区域。下图是此前诊断模型的一例四联图，只展示这种诊断方法，不冒充本次权重的可视化；上图才是本次模型的实际池化权重。

三、旋转搜索、局部匹配与整图融合

4. 旋转补偿。 此前合成旋转实验已确定描述子对大角度旋转敏感；硬按SIFT方向对齐图块反而使真实匹配退化。当前评价不强制硬对齐，而对查询位置从原图分别以 0°、−15°、+15°、−30°、+30° 重采样32×32图块并提取描述子，模板保持0°。比较五组候选，保留能够提供较好几何一致性的匹配。SIFT主方向仍用于候选对应的方向一致性检查。

5. 局部几何匹配。 在查询与模板的局部描述子间计算余弦相似度；先取双向最近邻，再用RANSAC筛出可被同一局部仿射变换解释的对应，叠加空间覆盖和方向一致性等诊断/评分。对同一声明手指，以20张模板和五角度查询候选寻找较优分数；验证集选择每折使用的候选评分方案。下图是此前匹配诊断的实际对应连线，用于直观展示几何关系。

6. 训练与融合。 第45版在每折训练手指上进行全模板、全角度难例挖掘；把原先易饱和的排名目标改为余弦间隔 softplus((0.12−(同指余弦−异指余弦))/0.1)，并约束正负余弦。模型轮数和候选评分方式仅由对应验证集选择。六折最佳轮为 0、4、0、0、0、0；五折保留初始权重，说明此次最终突破主要来自后续评分与融合方式，不能归功于“第45版训练普遍改善了网络”。

第50版不再训练，用相同局部描述子的均值经L2归一化构造整图向量。每一声明先分别取得局部几何原分数和整图余弦分数，再减去同一查询其他声明手指最高两分的均值，形成两路竞争边际。融合形式为 局部边际 + w×整图边际，其中 w=0.35×验证集局部边际标准差/验证集整图边际标准差，每折只从湿验证集估计；工作点阈值也只从该折验证集定出。第50版已保存逐声明原始分数、边际和融合分数，可逐项核对。该评分依赖注册身份集合，注册库变化须重新校准。

第51版对验证查询分层重采样200次后，复用相同测试折的FAR中位数为0.51%、FRR中位数为9.97%，显示小验证集定阈值的波动。当前全部湿图均已进入实验，缺少从未参与方案开发的新湿手指身份；此外六折按手指隔离而非按人隔离。这些限制不妨碍交付“现有数据上的开发性交叉验证结果”，但不能对外写成独立盲测或新用户泛化保证。

统一模型：第52版现有数据回测

六折模型结构一致，其中第2、5折权重完全相同；第52版将五份不同权重等权参数平均成一份约93万参数的模型，固定 orientation_top3 候选匹配规则，不针对回测结果挑选权重或规则。以统一模型重新从全部现有湿图提取描述子，并按每指20张湿模板、完整12指图库计算声明分数。每根手指按固定哈希把约1/3查询放进校准组，其余放进回测组：198张校准、404张回测。仅从校准组估计局部/整图融合系数与工作点阈值（FAR0.5%阈值约0.94254），然后在404张回测查询上使用同一份权重与阈值。

随附 交付文件夹：收录1082张湿图、一份统一模型、六折对照权重、固定校准/回测名单、原始声明分数及测试方案。运行 run_single.py --verify-images 可复算统一模型的0.38%/10.89%；旧的 run.py 复算六折0.47%/9.30%。这两个快速脚本复用已保存的模型输出，完整的原图评分源代码在第52版实验目录。下一阶段获得新湿手指后，应固定这份模型与注册/校准规则，在新身份上再做独立验证。

全 C 推理与评测链路

本周完成湿指纹流程的 C 化基线：将 model.pt 导出为 TinyDLC 图模型后，运行时由 C 读取模型参数，完成 ANSI C SIFT 关键点提取、32×32 局部块构造、128 维深度描述子推理、局部/整图融合匹配、候选身份排序、校准阈值确定及 FAR/FRR 统计；Python 仅保留为模型导出和对齐验证工具，不参与本次正式运行。全 C 实验严格复用固定协议，共602张查询、7224条身份声明，回测集包含4444条 impostor 声明和404条 genuine 声明；在目标 FAR=0.5% 附近得到实际 FAR 0.518%（23/4444）、FRR 19.06%（77/404）。该结果证明端到端 C 链路已能提取有效区分信息，且评测数据量与 Python 对照完全一致；当前与 Python/OpenCV 对照约10% FRR 的差距主要来自 C SIFT 的关键点选择、尺度/方向及 C RANSAC 的实现差异，后续将围绕这些局部匹配模块继续对齐。
